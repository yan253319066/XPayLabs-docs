XPayLabs（常称 **xpay**）是一个开源的自托管加密支付基础设施，让您能够通过单一 API 在多个区块链上接受和管理稳定币支付。**原生多商家架构** — 一个部署可入驻无限商家，每个商家拥有独立的 API 凭证和独立配置。自主设置费率，从每笔交易中获取收益。与托管式支付网关不同，XPayLabs 完全运行在您自己的基础设施上——您的私钥保留在您的服务器上，您的资金直接到达您的钱包，并且您支付零网关费用。每个网关实例每秒可处理多达 100 笔交易，无每笔交易费用——仅需支付区块链 gas 费用（每笔交易 $0.01–$0.50）。

## 支持的区块链

XPayLabs 原生支持以下区块链网络：

| 链 | 类型 | 稳定币 |
|---|---|---|
| **TRON** | TRC20 | USDT、USDC |
| **Ethereum** | ERC20 | USDT、USDC、DAI |
| **BNB Chain** | BEP20 | USDT、USDC、BUSD |
| **Polygon** | ERC20 | USDT、USDC、DAI |
| **Avalanche C-Chain** | ERC20 | USDT、USDC |
| **SUI** | 原生 | USDC |

## XPayLabs 如何处理支付？

<Steps>
  <Step title="部署网关">
    在您的服务器上运行 `docker compose up -d`。所有服务一起启动——Java 后端（xpay-user、xpay-merchant、xpay-eth、xpay-tron、xpay-sui）、区块链扫描器、Webhook 分发器和结账 UI。
  </Step>
  <Step title="生成 API 凭证">
    在网关管理面板中配置您的商家令牌。该令牌用于使用 HMAC-SHA256 签署每个 API 请求。
  </Step>
  <Step title="创建收款订单">
    发送包含金额、代币符号和链信息的 `POST /v1/order/createCollection` 请求。XPayLabs 返回一个唯一的充值地址和结账 URL。
  </Step>
  <Step title="监听 Webhook">
    注册您的回调 URL。当区块链扫描器检测到传入交易时，XPayLabs 会发送一个已签名的 webhook 通知。
  </Step>
</Steps>

## 核心概念

| 概念 | 描述 |
|---|---|
| **收款** | 生成唯一充值地址的支付请求 |
| **付款** | 从您的网关钱包到外部地址的资金划转 |
| **结算** | 自动将收到的资金从热钱包转入冷钱包 |
| **Webhook** | 由订单或收款状态变更触发的 HTTP 回调 |
| **扫描器** | 实时监控传入交易的区块链索引器 |

<Tip>
  由于 XPayLabs 是自托管的，您可以完全控制您的资金。没有第三方持有您的私钥，也不会从您的交易中扣除任何网关费用——您只需支付区块链网络 gas 费用。
</Tip>
