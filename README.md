# XPayLabs Docs

Documentation for [XPayLabs](https://www.xpaylabs.com) — a self-hosted, non-custodial crypto payment gateway. Built with [Mintlify](https://mintlify.com).

## Development

```bash
npm i -g mintlify
mint dev
```

Preview at `http://localhost:3000`.

## Structure

- Pages are MDX with YAML frontmatter
- Configuration in `docs.json`
- Static assets in `images/`

## Deploy

Push to the default branch — the Mintlify GitHub app auto-deploys to production.
